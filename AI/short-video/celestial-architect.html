celestial-architect（营造师） ​

celestial-architect-skill 是一套面向 AI Agent 的中文 Skill：把一张参考图、一句古诗或一个建筑关键词，营造成可直接用于 AI 生图的中式巨构、云上白玉京与仙侠场景提示词。

以《营造法式》《清式营造则例》中的建筑正名为骨架，结合郭熙三远法、样式雷图学与电影概念设计方法，写出形制准确、尺度宏大、构图清晰的中式幻想建筑提示词。

什么时候用 ​

说以下关键词即可触发：

  • 「营造师」「白玉京」「中式巨构」「中式赛博」「天上白玉京」
  • 给一张图，要求「参考构图/角度出中式巨构提示词」
  • 给古诗句或建筑关键词（亭/台/楼/阁/桥/檐/栈道等）
  • 给修仙门派场所或局部场景词（炼丹房/藏书阁/洞府秘境/园林/檐角一隅/漏窗等）

不适用：通用图片反推、视觉 DNA 裂变、一图生模板、其他风格的提示词生成。

两条风格路线 ​

路线气质光法
A 路｜云上白玉京（默认）少赛博，多仙气。科技作「不可见的承重」暖金自然光（晨金/夕金/体积雾）；夜景用月银 + 宫灯暖点
B 路｜宫城蓝线图冷光只描结构，像「未建成/正在显影」钴蓝全息线框叠在宫墙、斗栱上；朱墙金瓦仍在

文学锚点：李白「天上白玉京，十二楼五城」——仙都，不是夜店长安。

三个输入入口 ​

text
入口一：识图 → 构图基因移植（只移植机位与构图，元素转译为中式）
入口二：诗句 → 意象四抽（构件名词 / 动词空间 / 数量尺度 / 时间气象）
入口三：关键词 → 按景别路由（宏观巨构 / 门派场所 / 局部特写）

识图转译示例：

原图元素中式转译
哥特尖塔 / 教堂钟楼密檐塔 / 阙楼 / 重檐楼阁
玻璃幕墙 / 现代高层逐层收分的重檐楼身 + 隔扇窗
摩天楼天际线十二楼五城纵深宫城群

默认输出 ​

  • 单路线，同一场景，3 组互补视角（密 / 均 / 疏三档递减）
  • 每组先中文提示词，再英文提示词，两个独立代码块
  • 画幅默认 9:16 立轴；平远建立镜头可 16:9；藻井大样可 1:1
  • 提示词全部输出后，可复制到 Midjourney / 即梦等平台出图，或存档到本地 markdown

输出示例结构：

markdown
### 第 1 组｜{诗意标题}（A 路 · 高远 · 9:16）

```
{中文提示词}
```

```
{英文提示词}
```

三条铁律 ​

  1. 构件写死，术语用正名：禁止只写「中式建筑」。必须写到形制颗粒度——庑殿/歇山/攒尖、几踩斗栱、须弥座、鸱吻脊兽等
  2. 画面必有尺度感：远景巨构带比例尺（默认一人背影占画面下沿一角）；无人物时用飞鸟/舟楫/宫灯等替代锚
  3. 暖光打建筑，冷光只描边：冷光铺满就滑向霓虹街

参考资料 ​

Skill 自带四份 reference，写提示词时按需查：

文件内容
references/构件语汇库.md大木作/瓦石/装修/彩画正名、高冲击力词条、真实母本建筑
references/机位与图学.md三远法、借景机位库、样式雷图学五样
references/场景与室境.md修仙场所谱、园林场景、局部特写谱
references/黄金样例.md五组成稿示例，方向与颗粒度参照

安装 ​

从仓库下载 营造师.skill，解压后将技能目录命名为 celestial-architect，放进当前 Agent 的 Skills 目录。常见路径：

text
~/.claude/skills/celestial-architect/   # Claude Code
~/.codex/skills/celestial-architect/    # Codex
# 其他支持 Skill 的 Agent，目录结构类似

安装后目录结构：

text
celestial-architect/
├── SKILL.md
└── references/
    ├── 场景与室境.md
    ├── 构件语汇库.md
    ├── 机位与图学.md
    └── 黄金样例.md

怎么用 ​

安装后在 Agent 对话里直接说意图即可，例如：

调用 celestial-architect，参考这张图的构图和视角，营造成云上白玉京。人物使用古装小背影。
调用 celestial-architect，把"危楼高百尺，手可摘星辰"营造成天上白玉京。人物使用古装小背影。
调用 celestial-architect，营造一座悬在云壑之上的藏书阁，走 A 路，无人物。

Agent 负责生成提示词，不负责出图。提示词全部输出后，复制到外部生图平台使用：

平台说明
Midjourney仓库案例多用 MJ V8 测试，复杂巨构效果较好
即梦国内访问方便，支持参考图垫图
nano-banana 等按平台习惯粘贴中文或英文提示词

Skill 默认不会自动出图，也不会消耗生图额度。需要存档时，可将提示词保存到本地 markdown 文件。
