H 指数 ​

给你一个整数数组 citations ，其中 citations[i] 表示研究者的第 i 篇论文被引用的次数。计算并返回该研究者的 h 指数。

根据维基百科上 h 指数的定义：h 代表「高引用次数」，一名科研人员的 h 指数是指他（她）至少发表了 h 篇论文，并且至少有 h 篇论文被引用次数大于等于 h 。如果 h 有多种可能的值，h 指数是其中最大的那个。

题目链接 ​

https://leetcode.cn/problems/h-index/

示例 ​

示例 1：

输入：citations = [3,0,6,1,5]

输出：3

解释：给定数组表示研究者总共有 5 篇论文，每篇论文相应的被引用了 3, 0, 6, 1, 5 次。 由于研究者有 3 篇论文每篇至少被引用了 3 次，其余两篇论文每篇被引用不多于 3 次，所以她的 h 指数是 3。

示例 2：

输入：citations = [1,3,1]

输出：1

答案 ​

解法一：暴力枚举 ​

按定义枚举候选 h：从 1 扫到「引用大于 0 的论文数」，统计有多少篇论文引用次数 ≥ i，若至少有 i 篇，则更新答案。

js
/**
 * @param {number[]} citations
 * @return {number}
 */
var hIndex = function(citations) {
    let max = 0
    // 引用为 0 的论文对 h≥1 没有贡献，先缩小枚举上界
    let len = 0
    for (let i = 0; i < citations.length; i++) {
        if (citations[i] > 0) len++
    }
    for (let i = 1; i <= len; i++) {
        let temp = 0
        for (let j = 0; j < citations.length; j++) {
            if (citations[j] >= i) temp++
            if (temp >= i) {
                max = i
                break
            }
        }
    }
    return max
};

解法二：排序优化 ​

先按引用次数降序排序，再从前往后找最大的 h，满足「第 h 篇论文的引用次数 ≥ h」（下标从 0 起即 citations[h-1] >= h）。一旦不满足，后面只会更小，可直接结束。

js
/**
 * @param {number[]} citations
 * @return {number}
 */
var hIndex = function(citations) {
    citations.sort((a, b) => b - a)
    let h = 0
    for (let i = 0; i < citations.length; i++) {
        if (citations[i] >= i + 1) {
            h = i + 1
        } else {
            break
        }
    }
    return h
};

分析 ​

  • 解法一：时间复杂度 O(n²)，空间复杂度 O(1)。直接对应 h 指数定义，好理解，n ≤ 5000 时可通过。
  • 解法二：时间复杂度 O(n log n)（排序主导），空间复杂度取决于排序实现。排序后一次扫描即可定答案，更常见也更高效。
