概念 ​

防抖（debounce）和节流（throttle）都是用来限制函数执行频率的，但策略不同：

  • 防抖：一段时间（wait）内多次触发，只生效一次。常见于搜索输入、窗口 resize。
  • 节流：一段时间（wait）内多次触发，按固定间隔执行。常见于滚动监听、拖拽。

可以记成：防抖是「停下来再做 / 开头做一次然后冷却」；节流是「每隔一段时间做一次」。

防抖 debounce ​

支持两种模式（由 immediate 控制）：

  • immediate = true（头部）：首次立即执行，冷却期内忽略，适合点赞按钮。
  • immediate = false（尾部）：等停下来后再执行最后一次，适合搜索联想。
javascript
// 防抖：wait 内多次触发只生效一次。
// immediate=true：首次立即执行，冷却期内忽略（如点赞）；false：等停下来后再执行最后一次。
function debounce(func, wait = 50, immediate = true) {
  let timer = null; // 有值 = 冷却中；null = 可以再次触发
  return function (...args) {
    // 头部模式且当前不在冷却中 → 这次要立刻执行
    const callNow = immediate && !timer;
    // 每次触发都清掉旧计时器，重新开一段 wait 冷却
    clearTimeout(timer);
    timer = setTimeout(() => {
      timer = null; // 冷却结束，允许下次触发
      // 尾部模式：停满 wait 后才执行最后一次
      if (!immediate) func.apply(this, args);
    }, wait);
    // 头部模式：立刻执行（冷却期内的后续调用 callNow 为 false，会跳过）
    if (callNow) func.apply(this, args);
  };
}

逻辑说明：

  1. 闭包里的 timer：有值表示冷却中，null 表示可以再次触发。
  2. 每次调用都会 clearTimeout 并重新计时，所以连续触发会不断推迟「冷却结束」的时间点。
  3. 头部模式只在 !timer 时立刻执行；冷却期内再点只重置计时，不执行。
  4. 尾部模式不立刻执行，只在最后一次触发后满 wait 时执行。

使用示例：

javascript
const onSearch = debounce((keyword) => {
  console.log('search:', keyword);
}, 300, false); // 停输入 300ms 后再搜

const onLike = debounce(() => {
  console.log('like');
}, 1000, true); // 立刻点赞，1s 内重复点击无效

节流 throttle ​

节流保证在 wait 时间窗口内至少/至多按节奏执行。下面是一个同时支持「首次立即执行」和「结束后补一次」的常见写法：

javascript
// 节流：wait 内多次触发，按固定间隔执行。
// leading=true：窗口开始时立即执行；trailing=true：窗口结束时再补一次。
function throttle(func, wait = 50, { leading = true, trailing = true } = {}) {
  let timer = null;
  let previous = 0; // 上次真正执行的时间戳

  return function (...args) {
    const now = Date.now();
    // 禁止 leading 时，把 previous 设成 now，避免第一次立刻执行
    if (!previous && !leading) previous = now;

    const remaining = wait - (now - previous);

    if (remaining <= 0 || remaining > wait) {
      // 到点了：清掉尾部定时器，立刻执行
      if (timer) {
        clearTimeout(timer);
        timer = null;
      }
      previous = now;
      func.apply(this, args);
    } else if (!timer && trailing) {
      // 还没到点，但开启了 trailing：到期后再补一次
      timer = setTimeout(() => {
        // leading=false 时补完要把 previous 置 0，方便下一轮
        previous = leading ? Date.now() : 0;
        timer = null;
        func.apply(this, args);
      }, remaining);
    }
  };
}

两种简化版：

javascript
// 时间戳版：首次立刻执行，之后每隔 wait 执行一次（只有 leading）
function throttleLeading(func, wait) {
  let previous = 0;
  return function (...args) {
    const now = Date.now();
    if (now - previous >= wait) {
      previous = now;
      func.apply(this, args);
    }
  };
}

// 定时器版：首次触发后等 wait 再执行，停止触发后还会执行最后一次（只有 trailing）
function throttleTrailing(func, wait) {
  let timer = null;
  return function (...args) {
    if (timer) return;
    timer = setTimeout(() => {
      timer = null;
      func.apply(this, args);
    }, wait);
  };
}

使用示例：

javascript
const onScroll = throttle(() => {
  console.log('scroll', window.scrollY);
}, 200); // 滚动时大约每 200ms 回调一次
